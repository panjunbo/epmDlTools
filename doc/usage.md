# epmDlTools 使用说明

## 1. 安装依赖

```bash
pip install pyserial pycrc
```

## 2. CLI 模式

```bash
python epmDlTool.py -h
python epmDlTool.py flashload --dry-run
python epmDlTool.py programmer -programmer_bin_path bin/programmer.bin
```

## 3. GUI 模式

```bash
python epmDlTool.py --ui
```

### 3.1 界面布局

```
┌──────────────────────────────────────────────────────────────┐
│ 文件  帮助                                                  │
├──────────────────────────────┬───────────────────────────────┤
│ 串口配置                       │ 下载                          │
│  端口 / 日志波特率 / 下载波特率 │  下载目录 / 模式 / 核列表      │
│  参数: 8-N-1  [配置参数…]      │  [开始下载]   [进度条]         │
│  状态: 已关闭   [打开串口]      │                               │
├──────────────────────────────┴───────────────────────────────┤
│ 串口助手（接收区 / 日志）                                      │
│  接收区（显示下载流程日志 + 设备数据）                          │
│  发送区（HEX/ASCII、追加 \r\n、定时发送）                      │
│  ▶ 列表发送（默认隐藏，点标题展开）                            │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 关键约定

| 项 | 说明 |
| --- | --- |
| 端口 | **一个端口共用**（日志 = 下载）；下载波特率独立配置 |
| 串口参数 | 数据位/校验位/停止位 通过「配置参数…」按钮弹窗设置；面板仅显示摘要 `8-N-1` |
| 串口开关 | 单 toggle 按钮「打开串口」/「关闭串口」；失败时按钮状态自动回退 |
| 日志与接收区合并 | 「接收区」同时显示下载流程日志与串口接收数据；INFO/WARN/ERROR/ID 颜色区分 |
| 列表发送 | **默认隐藏**；点击「▶ 列表发送」展开/收起 |
| 多核 bin | 选目录 + 自动 `[OK]/[--]` 标记；一次下载按选中顺序烧录 |
| ID 日志 | 按核写入 `<bin_dir>/<core>_id.log`，无独立 UI |
| 配置自动读/写 | 启动时读入，关闭时写回；菜单 → 文件 → 保存配置 / 用文本编辑器打开 |

### 3.3 菜单

- **文件**
  - 打开配置文件
  - 用文本编辑器打开
  - 保存配置
  - 退出
- **帮助 → 关于**

### 3.4 串口助手使用

1. 在串口配置区点击「打开串口」按钮
2. 接收区实时显示：下载流程日志 + 设备返回数据
3. 在发送区输入（HEX/ASCII），可追加 \r / \n，支持定时发送
4. 点击「▶ 列表发送」展开预设列表；双击或选中点「发送选中」

### 3.5 串口切换与下载

1. 打开串口 → 助手接收区 + 日志同步显示
2. 点击「开始下载」→ 关闭串口 → 用下载波特率重新打开 → 跑协议 → 完成后自动恢复

## 4. 配置

`config/config.ini`：

| 段 | 字段 |
| --- | --- |
| `[serial]` | `log_port/log_baud/download_baud/data_bits/parity/stop_bits` |
| `[flashload]` | 默认擦/写参数 |
| `[programmer]` | 默认 bin 地址 |
| `[crypt_crc]` | 加密 CRC |
| `[bins]` | `default_dir` + `core_{a,b,c}_{name,file,addr}` |
| `[id_log]` | `core_{a,b,c}_log` |
| `[presets]` | `name_i/mode_i/data_i` 列表发送预设 |
| `[ui]` | 主题、窗口大小 |
